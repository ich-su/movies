## Запускатель фильмов. Web-версия

* **Год написания:** 2020
* **Язык:** PHP 8.1, JavaScript, CSS3
* **Версия:** 2.10

Техзадание изначально было примерно такое: на кухне на стене висит телевизор, подключенный по hdmi к компьютеру в соседней комнате. На компьютере куча дисков с фильмами и мультфильмами (такой себе видео-сервер). Рядом с телевизором лежит мышка. Нужна программа для быстрого запуска на телевизоре необходимого фильма/мультфильма желательно в три-четыре клика мышкой. 

Первые версии данной программы были написаны на Delphi. После был переход на web-технологии, поскольку на “сервере” поднялся PHP и пр. Заодно появились удаленный запуск фильмов и управление плеером через web-интерфейс.

Естественно, это все для домашнего использования.

Основные идеи: объединения фильмов с различных дисков в единую древовидную структуру, и выдача отсортированного списка по запросу от web-интерфейса по удобному поиску/фильтру, который позволяет это сделать только одной мышкой, но можно и с клавиатуры, даже игнорирую ошибку переключения раскладки клавиатуры.

Никаких баз данных нет. Вся информация о фильме находится в его названии файла: “Русское имя. Год выхода (Оригинальное название) Теги через запятую.расширение”. Год выхода, Оригинальное название, Теги необязательны.
